# 📊 Quarterly CRM Sales Dashboard

## 📌 Executive Summary
This project features an interactive dashboard built in **Google Sheets** to analyze sales tracking metrics. The main goal of this dashboard is to provide actionable business insights by transforming raw data into clear, visual Key Performance Indicators (KPIs).

> **Note:** This project was completed as a **guided case study provided by Maven Analytics**.

## 🔍 Business Problem
Maven Tech, a company specialised in selling computer hardware to large businesses started using a new CRM system to track their sales opportunities, however they have no visibility outside the platform. 

## 🛠️ Tools & Methods
* **Tool:** Google Sheets
* **Data Cleaning & Preparation:** Removed duplicates, handled missing values, standardized formats, and structured raw data for dynamic analysis.
* **Key Functions Used:** `QUERY`, `SUMIFS`, `VLOOKUP` / `XLOOKUP`, `INDEX/MATCH`, and Pivot Tables.

  
## 📈 Dashboard Features & Key Insights
* **Interactive Controls:** Filter views dynamically by Regional Office and Manager.
* **Key Insights:**
  * **Insight 1:** Sales opportunities in the West Regional Office peaked in Q4 with 27 deals, making it the highest-grossing department of the company during the quarter.
  * **Insight 2:** Sales in the Central Regional Office dropped 38 deals compared with Q3.
