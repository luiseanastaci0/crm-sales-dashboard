# 📊 [CRM Sales Dashboard]

## 📌 Executive Summary
This project features an interactive dashboard built in **Google Sheets** to analyze sales tracking metrics. The main goal of this dashboard is to provide actionable business insights by transforming raw data into clear, visual Key Performance Indicators (KPIs).
